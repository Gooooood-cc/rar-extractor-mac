# 解压 RAR - Mac 版

这是一个 macOS 小工具，用来双击或拖拽解压 `.rar` 文件。

## 下载

下载 `dist/解压 RAR-macOS.zip`，解压后得到 `解压 RAR.app`。

## 使用方法

1. 把 `解压 RAR.app` 放到 macOS 的“应用程序”文件夹，或用户目录下的 `Applications` 文件夹。
2. 将 `.rar` 文件拖到 `解压 RAR.app` 上即可解压。
3. 如需双击 `.rar` 自动解压：
   - 右键任意 `.rar` 文件
   - 选择“显示简介”
   - 在“打开方式”里选择 `解压 RAR.app`
   - 点击“全部更改...”

解压结果会生成在压缩包所在目录的同名文件夹中。如果同名文件夹已存在，会自动使用 `文件名 2`、`文件名 3` 这样的目录名。

## 系统要求

- macOS
- 系统自带 `/usr/bin/bsdtar`

## 说明

本工具只调用 macOS 系统自带的 `bsdtar` 解压 RAR 文件，不上传文件，也不读取压缩包中文档的内容。
